# Codecraft Solutions Next.js App Setup Guide

## Requirements
- Node.js (v18+) or runtime matching tech stack: Next.js, React, Tailwind CSS
- Package manager: npm / pip

## Installation
Run from within `codecraft-solutions/`:
```bash
npm install && npm run dev
```

## Running Tests
```bash
npm run build
```

## Environment Configuration
Copy `.env.example` or `.dev.vars.example` if present. Never commit production credentials or API keys.
